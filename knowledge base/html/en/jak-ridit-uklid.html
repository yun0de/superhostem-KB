Practical guides

Give cleaners access and verify completion

Set property instructions, send the team its own link and check the actual cleaning status.

1. Prepare property instructions

Open Cleaning and the relevant property's settings. Add the procedure, checklist and useful photos. Check how the job relates to checkout and the next arrival.

2. Create access for a specific team

Create a named link, select the required properties and add instructions. Send it to the worker or team. Use separate access for other teams so it can later be revoked independently.

3. Check the job and reported issues

The worker opens the link, uses the checklist and adds requested photos or an issue report. Track waiting, in-progress, completed or problem states. Open the detail before treating it as resolved.

If a job is missing, check the date, property, actual reservation and cleaning settings. A calendar link showing dates is not the full cleaning workflow.
