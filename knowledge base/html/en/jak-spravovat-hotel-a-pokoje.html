Practical guides

Work with hotels and rooms

A hotel groups rooms. Configure reservations and sources on the individual rooms that are actually rented.

Help centreLibrary

Hotel features require access

If hotel features are enabled, open the hotel settings and rooms under Properties. The hotel is a group, not a rentable room. Ask support about availability if the options are missing.

Create or assign a room

Use Add room or assign an eligible existing property. Read the warning about inheriting shared hotel settings before confirming. Check capacity, pricing and sources for each room.

Do not blindly convert an occupied property

Conversion has prerequisites and existing reservations do not move automatically. If the property has dependent records, use a new empty hotel and follow the app's assignment process. Each room counts separately towards billed units.
