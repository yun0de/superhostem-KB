Register for the local stay fee

Start with the municipality for the property's address. Obtain its rules and payment details, then configure the property.

Help centreLibrary

  2. 2File notification
  3. 3Keep details
  4. 4Set up app

1. Find the correct authority

Use the official municipality or district website for the accommodation address to check whether the fee is charged, its rate, exemptions and notification deadline. Do not use another municipality's rules.

2. File the required notification

Use the current form and submission method published by the authority. Prepare operator and accommodation details requested in the form. Fee registration does not replace other operating permissions.

3. Keep details for future periods

Record the rate, bank account, payment reference, any registration number and payment deadlines. Check required records and communication method. Not every municipality uses monthly periods.

4. Configure the property

Enter the details in the property's fee settings. Verify the first calculation against actual guests, nights and exemptions. A generated PDF is not automatically a filed report and a QR code is not proof of payment.
