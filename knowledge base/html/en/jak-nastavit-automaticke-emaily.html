Set up automatic emails in Superhostem

Create one message for arrival, departure or registration completion. Choose its recipient and timing, check the preview, then verify actual sending.

Help centreLibrary
  1. 1Choose the property
  2. 2Set the event
  3. 3Check the preview
  4. 4Check send history

1. Open the property's message automation

Open the property and its Message automation. Switch to emails and create a rule. Give it a name you can recognise later.

This is an email sent by Superhostem. Messages inside Airbnb or Booking use the platform's own settings.

2. Choose the event, timing and recipient

  • Event: check-in, check-out or registration completion.
  • Timing: the offset before/after the event and available time settings, including the time zone.
  • Recipient: the reservation guest or a fixed email address.
  • Language: the guest's language and any fallback version.
Example first rule

Arrival reminder one day before check-in → reservation guest → short arrival instructions. First check that the stay has a guest email address.

3. Write the message and check the preview

Enter the subject and body. Select variables from the editor, such as {{guestName}}, {{propertyName}} and {{checkInDate}}. Check the preview for a specific reservation: recipient, dates, language and rendered content.

Save the automation and check that it is active. If a platform already sends the same message, check that you are not sending unnecessary duplicates.

4. Verify actual sending

In automatic email history, find the reservation, recipient, time and status, then open the detail. A preview checks content; it does not confirm sending or delivery to the guest's inbox.

  • No entry: check the active rule, property, event, timing and recipient contact.
  • Error: read the detail and correct the stated cause.
  • Sent but missing: check the email address and spam folder. A preview is not proof of delivery.

For last-minute stays, compare the rule's time with the actual arrival. Send a message manually if the guest needs it now.
