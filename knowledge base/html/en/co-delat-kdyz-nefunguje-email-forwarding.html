Fix reservation email forwarding

Check the address, Gmail verification and filter. If the email arrived but the stay is missing, check processing and matching.

Help centreLibrary
  1. 1Address
  2. 2Verification
  3. 3Filter
  4. 4Result

1. Copy the correct address

Open Email forwarding in Superhostem. Copy the assigned address and compare it with the destination in your mail settings. Make sure you are configuring the correct Gmail account.

2. Finish Gmail verification

Gmail sends verification to the added destination, not another personal inbox. Complete it using the instructions shown in Superhostem, then return to the correct Gmail account settings.

3. Check the filter and forwarding action

Check the conditions and the action to forward to your Superhostem address. The filter must match a real reservation email. Do not forward your entire personal inbox. Address verification does not create the filter.

4. Forwarded email, missing reservation

Use an original supported reservation email, not self-written test text. Check the platform, property and reservation reference. Give support the subject, sender and forwarding time so they can check processing and matching in admin diagnostics.
