Before you start hosting

Check operating permissions, local fees, guest records and foreign-guest reporting duties. Reuse existing registrations if you already have them. Creating an account does not confirm legal compliance.

Check legal requirements and registrations

Create one property

On Overview, choose the source you actually use. If you have iCal, enter the export URL for the correct listing and a property name. Without an import, create a property manually under Properties. Instructions depend on the selected source; this is not limited to Airbnb.

Verify the first reservation

Open one stay in Reservations and check the property, dates and guest count. Add direct stays manually. Send the guest form, check completion, then verify any Ubyport reporting.

Add forwarding, guest guides, cleaning and automation gradually. Check each feature on one stay first.
