I want an email from Superhostem

Open Message automation and emails at the property. Set the event, timing, recipient and language. Check a reservation-specific preview and send history.

Set up automatic emails step by step

I want an Airbnb or Booking message

Create a template or scheduled message in the platform's messaging settings. Insert the correct Superhostem property link and assign it to the correct listing. Access to the reservation through that link must start no later than sending; the number of days does not have to be identical.

Before enabling automation

  • The link and template belong to the correct property.
  • The instruction is clear: confirm the stay, complete registration or open the guide.
  • You checked time zone, last-minute stays and available contact.
  • Two rules do not send the same message.

Start by sending one stay's form manually. Enable automation after checking the full journey, then verify actual sending.
