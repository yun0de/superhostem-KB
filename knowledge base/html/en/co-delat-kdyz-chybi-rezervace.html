What to do when a reservation is missing

Check the property and date filters first, then follow the source the reservation should arrive from.

Help centreLibrary

  2. 2Source
  3. 3Sync
  4. 4Verify

1. Rule out a hidden record

Clear the status filter in Reservations, check the dates and switch between past and upcoming stays. Check the correct unit and active organisation if you use one.

2. Check the source

  • iCal: the source must contain the dates. Check the full export URL for the correct unit and run the available sync action.
  • Email: check that the original supported reservation email was forwarded to your account's address. A self-written test message does not create a reservation.
  • Direct stay: create a manual reservation if it has not already been imported from another source.

3. Distinguish a stay from a blocked date

An occupied calendar date does not necessarily represent a guest reservation. Two sources can also show the same stay. Check dates, guest and source before creating a manual duplicate.

If the stay is still missing

Give support the property, dates, source, last check time and reservation reference. Import reports and some diagnostic screens are admin-only; ask support to check them if they are unavailable to you.
