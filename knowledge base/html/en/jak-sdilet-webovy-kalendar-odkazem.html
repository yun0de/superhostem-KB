Share a web calendar link

Share selected properties with a team or temporary collaborator, control visible details and revoke access later.

Help centreLibrary

Create a named link

Open Web overview in iCal export. Name the link and select properties. Choose the available visibility options for guest name, guest count, price, property and reservation status. For multiple properties, choose a suitable calendar or Gantt default view.

Review and share

Check the preview, create the link and send the complete URL to its recipient. No recipient account or calendar app installation is needed. Anyone holding the link can see the permitted overview; do not publish it openly.

Change or end access

Edit the available visibility options on an existing managed link and verify the shared page. Revoke unused access and use separate links for different teams. Enable cleaning mode only where the recipient should perform cleaning tasks.

Missing guest name or price

Check that the link permits the details and that they exist in the reservation. iCal may not include them; supported reservation emails or manual edits can add them. Forwarding does not guarantee every field from every email or immediate updates.
